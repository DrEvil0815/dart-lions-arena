# Version 4.7 – Bot ohne Handicap

- Bei Auswahl „Bot“ wird der Handicap-Modus samt Unterfeldern ausgeblendet.
- Für Bot-Matches werden gleiche Startpunkte und die allgemeine Checkout-Regel genutzt.
- Beim Wechsel zurück zu Gast oder registriertem Spieler wird die vorherige Handicap-Auswahl wiederhergestellt.
- Kinderprofile ohne E-Mail sind noch nicht über die Gegnersuche auswählbar. Dafür benötigen wir eine eigene, berechtigungsgeschützte Profilverwaltung und Profilauswahl.
