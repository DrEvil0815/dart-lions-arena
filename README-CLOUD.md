# Dart Lions Arena – Cloud-Test v0.1

1. Alle Dateien dieses ZIPs gemeinsam in dasselbe GitHub-Pages-Repository hochladen.
2. Anmeldung oben in der App mit dem bereits angelegten Testbenutzer testen.
3. Profil wählen, Kids Academy > Highscore spielen (10 Aufnahmen).
4. Nach Abschluss den Cloud-Status lesen. Bei Erfolg Supabase > training_sessions und training_throws prüfen.
5. Unter Kids Academy > Meine Ergebnisse auf ERGEBNISSE LADEN oben klicken, um Cloud-Ergebnisse abzurufen.

WICHTIG: Noch keine öffentliche Freigabe für Kinderkonten. RLS ist zwar eingeschaltet, aber Zugriff mit zwei verschiedenen Benutzern muss vor Veröffentlichung getestet werden. Bestehende lokale Ergebnisse werden NICHT automatisch importiert. Bei fehlender Verbindung bleiben neue Ergebnisse lokal. Diese Version speichert nur Kids-Trainings in der Cloud, keine normalen Matches.
