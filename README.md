Dart Lions Arena V3.0 – Ergebnisdialoge

Kids: Nach 10 Highscore-Aufnahmen öffnet sich automatisch ein Ergebnisdialog mit Punkten, 3-Dart-Average, Darts und Aufnahmen. Andere Übungen öffnen ihn bei Spielende; manuelles Abschließen bleibt möglich. Beenden zeigt die Ergebnisliste; Neustarten setzt die aktuelle Übung zurück.

Scorer: Nach Matchgewinn erscheint ein Dialog mit Sieger, Leg-Ergebnis, Sieger-Average und 180ern. Beenden führt ins Hauptmenü; Neustarten startet mit denselben Einstellungen neu.

Alle 8 Dateien in GitHub hochladen, inklusive neuer results.js.


## V3.1 – Vollbildmodus
Beim Klick auf eine Spielart wird auf unterstützten Desktop-Browsern der Vollbildmodus angefragt. Im Header steht jederzeit ein Vollbild-Schalter. Unten links erscheint im Vollbild der Hinweis „Vollbild beenden: Esc“. Esc beendet den Modus browserseitig. Browser verlangen eine aktive Nutzeraktion; ein automatischer Vollbildstart beim Laden ist nicht möglich. Auf manchen Mobilbrowsern wird die Fullscreen-API nicht unterstützt.
