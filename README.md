# Dart Lions Trainings-Arena V0.6

GitHub Pages: Dateien `index.html`, `style.css`, `script.js` direkt in das Repository-Hauptverzeichnis hochladen und ersetzen.

Änderungen: dreispaltiges Layout mit zentraler Punkteingabe, aktiver Spieler vergrößert und hervorgehoben, exklusive Aufnahme-Kategorien (40–59, 60–79, 80–99, 100–179, exakt 180), Checkout-Vorschläge bei <=170 Rest, Spielernamen und Legstand zentral.

Checkout-Vorschläge sind Empfehlungen, keine Garantie für den optimalen Weg. Exakte Punkteingabe auf 0 gilt weiterhin als bestätigtes gültiges Finish. Bei einem Bust wird keine Trefferkategorie gezählt. Der 3-Dart-Average und Short-Leg-Zähler schätzen weiterhin 3 Darts je Aufnahme.

Die Anzeige nutzt dynamische Viewport-Höhen. Auf sehr kleinen Bildschirmen oder bei Browser-Zoom kann Scrollen nötig sein.
